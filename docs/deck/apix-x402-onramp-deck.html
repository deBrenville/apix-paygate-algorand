01 / 06

The problem

Agents can't use paid APIs the way humans do

  • No one to sign up, enter a card, solve a CAPTCHA, or run OAuth.
  • And even once payment is solved — how does an agent find the service and its price?
  • Today a human onboards every single API. That doesn't scale to an agent economy.

02 / 06

The insight

Payment is solved.
Discovery is the missing half.

x402 + the GoPlausible facilitator already let any endpoint charge in USDC — no accounts, no infrastructure.

The gap is discovery — and that is uniquely APIX's.

Fuse the two into one zero-code step: discoverable and payable — the half Algorand's ecosystem lacks.

03 / 06

The product

One config entry → discoverable + payable

  • Paygate is a reverse-proxy gateway — point it at any existing API…
  • …and it becomes discoverable (auto-registered in the APIX index, HATEOAS)…
  • …and payable (x402 on Algorand enforced at the gateway) — zero paywall code.
  • And it composes: services discover and pay services — paid, discoverable chains.

04 / 06

The live demo — a cascade

Agent → humanity layer → neutral ledger

  • Agent searches by capability (HATEOAS — knows only its goal), pays B.
  • B discovers and pays A — a second on-chain hop.
  • A returns every match as evidence + score. Stateless.
  • B applies the pro-humanity filter: OFAC-only + humanity-serving → MATCH_EXEMPT, provenance kept.
