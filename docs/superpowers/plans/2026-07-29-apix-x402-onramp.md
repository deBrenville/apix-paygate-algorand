# APIX x402 Onramp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Quarkus reverse-proxy gateway that makes any HTTP API discoverable in the APIX index (BSM) and payable via x402 on Algorand testnet with zero paywall code on the provider side; demonstrated by a flagship sanctions-screening upstream (with a pro-humanity exemption layer) and a trivially-wrapped second upstream.

**Architecture:** One standalone Quarkus app. A JAX-RS request filter enforces x402 (402 → GoPlausible facilitator verify/settle → reverse-proxy to a per-route upstream with a signed forward header). Upstreams are config entries. A BSM publisher exposes machine-readable discovery per route. The sanctions upstream reuses the real `SanctionsMatcher` from `apix-verification`. A Java demo agent (algosdk) drives the full discover→pay→screen→decide loop for the video.

**Tech Stack:** Java 21, Quarkus (RESTEasy Reactive, REST Client Reactive), Algorand Java SDK (`com.algorand:algosdk`), `apix-verification` (real sanctions matcher), JUnit 5 + REST-assured, Maven. GoPlausible facilitator (`facilitator.goplausible.xyz`), Algorand **testnet**, USDCa.

## Global Constraints

- **Language of all repo content: English** (OSS rule; also required by hackathon Official Rules §12a).
- **Single technology: Quarkus/Java.** The only permitted exception is a throwaway TS/Python helper to generate an `X-PAYMENT` payload *inside the demo client only* — never in the service — and only if Task 2 proves the pure-Java path infeasible.
- **Network: Algorand testnet.** Price asset = an **ASA** — testnet USDC (`10458941`) by default, or a self-minted ASA (`price-asset-id` config). **Native ALGO (`asset:"0"`) is NOT usable — the facilitator rejects a `pay` txn and requires an `axfer`** (proven by the spike). Mainnet is out of scope (config flip only).
- **Claude never handles keys/wallets/funds.** The testnet wallet mnemonic + funded USDCa are supplied by Carsten via an env var / untracked file; never commit them; `.gitignore` must exclude them.
- **x402 wire formats (from GoPlausible docs, to be pinned by Task 2):**
  - 402 body: `{ x402Version: 2, accepts: [PaymentRequirements], error? }`.
  - `PaymentRequirements` = `{ scheme:"exact", network:"algorand:<CAIP-2 genesis-hash-b64>", maxAmountRequired:"<micros str>", resource, description, mimeType:"application/json", payTo:"<algo addr>", maxTimeoutSeconds:60, asset:"<ASA id>", extra:{ name:"USDC", decimals:6 } }`.
  - `X-PAYMENT` value = JSON `{ x402Version:2, scheme:"exact", network:"algorand:...", payload:{ paymentGroup:[<b64 msgpack signed payment txn>, <b64 msgpack unsigned fee-payer txn>], paymentIndex:0 } }` (confirm JSON-vs-base64-of-JSON transport encoding in Task 2).
  - Facilitator: `POST /verify {paymentPayload, paymentRequirements} → {isValid, ...}`; `POST /settle {paymentPayload, paymentRequirements} → {success/txId, ...}` (exact field names pinned in Task 2 against `facilitator.goplausible.xyz/docs`).
